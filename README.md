# Claude Stack

Conjunto de ferramentas para otimizar, organizar e aprimorar o uso do Claude Code.

## Componentes

- **Agent Skills** — workflows especializados de engenharia de software.
- **Ponytail** — incentiva soluções simples e evita overengineering.
- **RTK** — reduz a saída desnecessária do terminal antes que ela chegue ao modelo.
- **Headroom** — comprime contexto, saídas de ferramentas, logs e dados grandes.
- **shadcn UI MCP** — fornece contexto sobre componentes, blocos, uso e instalação do shadcn/ui.
- **Impeccable** — melhora a qualidade visual e a consistência de interfaces.

## Princípio

> Use somente o que for necessário para a tarefa atual.

Ter uma capacidade disponível não significa que ela deva ser utilizada em todas as tarefas.

## Como funciona

Este repositório funciona como uma camada de organização e roteamento. As ferramentas continuam sendo mantidas por seus projetos oficiais; este repositório não copia seus códigos-fonte.

A skill `claude-stack` orienta o Claude sobre quando cada capacidade é relevante.
