# Claude Stack

Conjunto de ferramentas para otimizar, organizar e aprimorar o uso do Claude Code.

## Ferramentas

- Agent Skills
- Ponytail
- RTK
- Headroom
- shadcn UI MCP
- Impeccable

## Objetivo

Centralizar e organizar diferentes ferramentas e recursos para o Claude Code,
permitindo que cada recurso seja utilizado somente quando for relevante para
a tarefa atual.

O objetivo é evitar uso desnecessário de ferramentas, contexto e tokens,
mantendo um único agente principal.

## Princípio

> Utilize somente o que for necessário para realizar a tarefa.

As ferramentas não devem ser acionadas simplesmente por estarem disponíveis.
Cada recurso possui uma finalidade específica e deve ser utilizado de acordo
com a necessidade do projeto.

## Estrutura

Este repositório funciona como uma camada de organização e configuração.
As ferramentas continuam sendo mantidas por seus respectivos projetos
originais.
